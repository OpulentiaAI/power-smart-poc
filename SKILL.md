# Power Smart scenario router
Production: run `npm run workflows:prepare`, enter `workflow-environments/production/runtime`, then follow the matching order, warranty, or SPS production skill.
Demonstration: enter `workflow-environments/demonstration/runtime`, invoke `power-smart-illustrated-demo`, and update the Dither dashboard plus evidence ribbon every scene; email is draft-only and never sent.
Never read from the sibling runtime; credentials, inputs, outputs, and artifacts stay inside the selected scenario folder.
